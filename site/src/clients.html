Add it to an MCP client

Use the absolute path to the built file, for example "$(pwd)/dist/index.js" from the clone.

Claude Code over stdio (agents on this machine):

claude mcp add message-cp -- node /absolute/path/to/message-cp/dist/index.js

Claude Code over HTTP (agents on any machine; needs a running server, see Running the HTTP server):

claude mcp add --transport http message-cp https://message-cp.example.com/mcp --header "Authorization: Bearer <token>"

To have every session the client opens act as one agent from its first request, with no register call, add its name and key as two more headers (see Sessions under Running the HTTP server):

claude mcp add --transport http message-cp https://message-cp.example.com/mcp --header "Authorization: Bearer <token>" \
  --header "X-Message-CP-Agent: <name>" --header "X-Message-CP-Agent-Key: <key>"

The URL is your proxy's public address followed by /mcp. To try it on the server's own machine without a proxy, use http://127.0.0.1:8787/mcp.

To make that command in one step, run connect on the server: node dist/cli.js connect <name> --url https://message-cp.example.com creates the agent <name> with a new key, makes an agent token, and prints the command above filled in, followed by the same server as a JSON mcpServers entry for other clients.

Cursor over stdio (.cursor/mcp.json in the project, or ~/.cursor/mcp.json):

{
  "mcpServers": {
    "message-cp": {
      "command": "node",
      "args": ["/absolute/path/to/message-cp/dist/index.js"]
    }
  }
}

Every stdio server started this way opens the same database, so an agent registered in one session is visible from every other. Set MESSAGE_CP_DB in the server's environment to use a file other than the default (see Settings).
