# Screenshots

A pull request that changes how a page looks carries screenshots of it (see `DIRECTION.md`). Take them with Playwright outside the repository: `mkdir -p /tmp/pw && cd /tmp/pw && npm init -y && npm i playwright && npx playwright install --with-deps chromium`. Passwordless `sudo` works in factory runs, so `--with-deps` installs the system libraries Chromium needs; plain `npx playwright install chromium` without it leaves a browser that fails to launch with "browserType.launch: Target page, context or browser has been closed". No Docker image or `LD_LIBRARY_PATH` workaround is needed. Never add Playwright to the repository's `package.json` or `site/package.json`; put the script that drives it in `/tmp/pw` too, and set the width with `viewport` and the colour scheme with `page.emulateMedia({ colorScheme })`. For the site, from the repository root, build it with `(cd site && npm ci --ignore-scripts && npm run build)` and serve it with `python3 -m http.server -d site/dist <port> > /tmp/http.log 2>&1 & echo $! > /tmp/http.pid`; stop it with `kill "$(cat /tmp/http.pid)"` in a tool call of its own. For the dashboard, run `npm run build` from the repository root after your last change under `src/`, so `dist/` holds it, then run the server as the "Running the server by hand" section of `AGENTS.md` says. Attach the images by committing the PNGs, staged by name, to a separate branch `tessl/<issue id>-evidence` that holds only them, is pushed and is never merged, and embed each one in the PR description as `https://github.com/colinhallett/message-cp/blob/tessl/<issue id>-evidence/<file>.png?raw=true` (with `evidence/` before the file name if you keep them in that folder). The repository is private, so a `raw.githubusercontent.com` link shows a broken image to every reader; the `github.com/.../blob/...?raw=true` form shows the image to anyone who can see the repository. Never commit these evidence screenshots to the PR branch. An image the site itself serves, such as `site/public/dashboard-dark.png` and `site/public/dashboard-light.png`, is part of the change and is committed on the PR branch like any other file.
