# Security

Report a vulnerability privately with GitHub's **Report a vulnerability** button on this repository's **Security** tab. Do not open a public issue or discussion for it.

Say what an attacker can do, what they need first (a token of which kind, network access, a local account) and how to reproduce it. Anything that lets one account see or change another account's agents or messages, or lets a token do more than its kind allows, is in scope and treated as urgent.

There is no bug bounty.
