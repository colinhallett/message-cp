# Review lenses

The Tessl Code Review lenses this repository reviews pull requests with, routed
by `.tessl-code-review.yml` at the repository root. They started as exact
copies of the six lenses in `tessl/code-review@0.5.0` and are tuned here for
message-cp. Each change to a lens says what review evidence it rests on.

These files, and `.tessl-code-review.yml`, are the owner's: the factory may
propose changes to them but never merges them, because a pull request is
reviewed with its own copy of them.
